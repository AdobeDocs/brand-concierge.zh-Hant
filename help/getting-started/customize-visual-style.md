# 自訂禮賓的視覺風格

您的Adobe Brand Concierge從Adobe已為您做出的視覺選擇開始，也就是從您的網站中拉取的調色盤、字型和卡片影像。 在本影片中，您將會檢閱這些選擇，並自訂歡迎訊息和入門提示卡，以更符合您的品牌。

## 這部影片是給誰看的？

* 品牌和行銷團隊
* 內容設計人員和撰稿人
* 任何微調門房外觀的人

## 視訊內容

* Brand Concierge如何從您的網站取得其入門色彩、字型和卡片影像
* 如何測試預設的桌上型電腦和行動裝置外觀
* 如何編輯歡迎訊息標題和副標題，包括文字顏色、粗細和大小
* 如何新增、移除和編輯入門提示卡 — 包括卡片文字、影像和背景顏色
