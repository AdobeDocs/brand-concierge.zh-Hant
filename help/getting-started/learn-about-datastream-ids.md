# 瞭解資料串流ID

瞭解資料串流ID如何將您網站上的Web SDK事件連線到Adobe Experience Platform中的Adobe Brand Concierge。 您會瞭解為何需要ID、它如何將資料路由到正確的沙箱和資料集，以及團隊如何將不同的資料串流用於開發、測試和生產。

* 團隊為何將不同的資料串流用於開發、測試和生產
