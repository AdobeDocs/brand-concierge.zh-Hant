# 部署禮賓

部署Adobe Brand Concierge可讓真正的網站訪客使用該工具。 此影片說明如何設定資料流以追蹤訪客參與情形，然後設定表面設定以控制禮賓在哪些頁面和網域上出現。

## 這部影片是給誰看的？

* 行銷人員將門房部署至其網站
* 提供資料流ID並安裝指令碼的IT或網頁開發團隊
* 團隊控制門房在其網站上的顯示位置

## 視訊內容

* 在Adobe Experience Platform中，如何在「資料收集>資料串流」下找到資料串流ID
* 如何新增資料流設定並複製產生的安裝指令碼
* 元件安裝與指令碼的完整頁面安裝選項比較
* 如何透過比對領域和路徑（任何、開頭為、結尾為、等於）來設定曲面規則
