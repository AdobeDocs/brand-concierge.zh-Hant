# 使用Adobe CX Enterprise Coworker匯出交談

瞭解如何使用Adobe Experience Platform查詢服務和Adobe CX Enterprise Coworker儲存和匯出Adobe Brand Concierge交談。 本影片說明如何在貴組織有可用的資料Distiller時，尋找資料集表格名稱、要求日期範圍的交談資料及下載CSV。

## 這部影片是給誰看的？

* 需要匯出Brand Concierge交談資料的開發人員

## 視訊內容

* 在Experience Platform中尋找交談資料集並複製其表格名稱
* 要求同事從指定日期範圍的回應表格中擷取資料
* 瞭解為何影片中顯示的CSV下載需要Data Distiller
* 儲存可能包含個人識別資訊(PII)的匯出專案時，請遵循您組織的資料處理原則

>[!VIDEO](https://video.tv.adobe.com/v/3504555?captions=chi_hant)

>[!NOTE]
>
> 如果您的組織無法使用Data Distiller，Co-worker將無法建立此影片中顯示的CSV下載專案。 選取[觀看[查詢服務]和[終端機]影片](exporting-conversations-using-query-service-and-terminal.md)，瞭解如何使用[終端機]將交談資料匯出至CSV檔案。

如需相關檔案，請參閱[Brand Concierge說明](../documentation/overview.md)。
