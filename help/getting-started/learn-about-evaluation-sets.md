# 瞭解評估集

評估可告訴您您的Adobe Brand Concierge是否正確回答、保持在範圍內，以及安全處理複雜的問題。 本影片會逐步解說三種評估型別（功能、超出範圍和保護），並示範如何建立評估集、執行評估集，以及在您上線前檢閱標幟的結果。

## 這部影片是給誰看的？

* 準備啟動的行銷人員和內容擁有者
* 在上線之前驗證禮賓回應的人
* 負責禮賓品質和安全的團隊

## 視訊內容

* 三種評估型別：功能、範圍外及保護
* 如何建立評估集 — AI產生的問題或您自己的CSV上傳
* 如何執行評估並檢閱整體分數和標幟的問題
* 如何比較禮賓人員的實際回應，與每個標幟問題的預期回應
