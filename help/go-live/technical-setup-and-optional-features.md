# 技術設定和選購功能

為Adobe Brand Concierge準備您的網站，並選擇支援訪客體驗的選用功能。 本影片說明部署需求、將禮賓新增至網站的方式，以及會議預訂、即時聊天和Marketo Engage的整合。

## 這部影片是給誰看的？

* 網站開發人員和管理員
* 行銷技術團隊

## 視訊內容

* 部署需求：標籤管理系統或手動新增的程式碼片段、目標頁面、Adobe Experience Platform沙箱和IMS組織，以及資料流
* 使用標籤管理員將禮賓新增至您的網站，或直接新增至您的程式碼基底
* 設定與代表的會議預訂、可用性和排程詳細資料
* 透過代表可用性、訪客觸發器和會議預約遞補啟用即時聊天
* 連線Marketo Engage以接收銷售機會和活動，具有管理員存取權和功能標幟
