# 建置並測試您的第一個Brand Concierge

本文涵蓋章節&#x200B;**1.2**、*建立及測試您的第一位禮賓*。 它會逐步解說如何建立門房，以及準備進行檢閱，從初始設定到分享意見回饋。

## 開始之前

在建立您的第一個服務人員之前，請先收集下列資訊。

- **品牌的網站URL：**&#x200B;這是建立第一個門房的唯一必要輸入。 Composer會自動讀取並草擬大部分的其他設定。
- **確認已授與Brand Concierge的存取權：**&#x200B;請參閱第3節。 如果無法登入，則是IT或管理員工作，且本指南中未解決。
- **產品卡資訊：**&#x200B;針對回應中的產品卡，請準備AEM Sites或內容AI連線，或產品試算表，其中包含產品目錄的名稱、說明、影像和連結。
- **Adobe Commerce詳細資料：**&#x200B;若為Adobe Commerce客戶，請從商務或IT團隊取得環境ID、商店代碼及API金鑰。
- **15-30分鐘不間斷的時間：**&#x200B;大部分的設定都涉及檢閱和輕輕編輯AI產生的草稿，而不是從頭開始編寫內容。

## 步驟1：設定門房並在預覽中測試

1. 移至5.1節&#x200B;*服務人員建立*，並使用網站URL建立服務人員。
2. 使用幾個代表性訪客問題在即時預覽中測試。

## 步驟2：自訂品牌體驗

1. 調整建立時草擬的品牌運算式和品牌描述檔（第5.1節）。
2. 檢閱並調整門房指示和護欄（第5.6節）。
3. 調整色調和語音、視覺風格和聊天元件，以符合品牌需求（第5.7-5.9節）。

## 步驟3：執行評估

1. 移至Section 6， *評估*，並為每個評估型別（功能、超出範圍以及保護）建立評估集。
2. 在繼續之前，請先執行評估並檢閱標籤的結果。

## 步驟4：建立可共用的預覽連結

1. 移至5.11區段&#x200B;*分享預覽連結*，並產生門房目前預覽的連結。
2. 與利害關係人共用連結以取得意見回饋，不需要他們擁有撰寫器存取權。

一旦客服人員經過自訂、評估及檢閱後，請參閱第7節&#x200B;*部署*，使其可供真正的訪客使用，接著是第8節&#x200B;*上線檢查清單*&#x200B;和第9節&#x200B;*Analytics*。
