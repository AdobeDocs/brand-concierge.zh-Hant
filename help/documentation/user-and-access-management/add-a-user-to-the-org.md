# 新增使用者至組織

在使用者存取Brand Concierge之前，請先在Adobe Admin Console中將使用者新增到Adobe Experience Platform組織。

## 先決條件

* 您必須擁有組織的管理員存取權。
* 使用者必須可以個別新增，或透過大量使用者上傳取得。

## 新增使用者

1. 前往&#x200B;**Admin Console**。
2. 選取&#x200B;**管理**&#x200B;或移至&#x200B;**使用者**。
3. 個別新增使用者，或透過大量上傳新增多個使用者。
4. 如果使用者不在組織中，請選取選項，在提示時將該使用者新增為新使用者。
5. 選取產品設定檔：

   * **Adobe Experience Platform**
   * 預設使用者設定檔

6. 選取「**儲存**」。

使用者會收到電子郵件邀請，確認存取組織。

>[!IMPORTANT]
>
>組織邀請可讓使用者存取組織，但不會授與Brand Concierge的存取權。 若要提供Brand Concierge存取權，請依照「使用Brand Concierge許可權建立角色」（連結）中的說明，建立並指派具有Brand Concierge許可權的角色。

## 後續步驟

將使用者新增至組織後，建立具有&#x200B;**管理Brand Concierge**&#x200B;許可權的角色，並將使用者指派給該角色。
