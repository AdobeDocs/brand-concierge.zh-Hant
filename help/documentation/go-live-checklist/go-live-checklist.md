# 禮賓處的上線檢查清單

使用此檢查清單完成啟動前的準備程度審查，之後才能讓真正的訪客可以使用禮賓服務。 檢查清單整合了知識來源、服務人員管理、評估和部署工作流程中所述的整備標準。

>[!NOTE]
>
>請考慮將此檢查清單發佈為獨立頁面。 獨立頁面可直接從Launch通訊連結，且獨立於完整檔案集參照。

## 如何使用此檢查清單

在啟動前完成每個料號，並記錄任何需要後續追蹤之料號的擁有者或證明。 除非適當的產品、品質或啟動專案擁有者已檢閱並接受風險，否則請勿針對未解決的問題繼續上線。

## 內容和設定

- [ ] **知識來源已完全處理。** 確認所有已設定的知識來源都已完成處理，且&#x200B;**修正問題**&#x200B;中沒有未解決的錯誤。
- [ ] **品牌運算式和品牌設定檔正確。** 檢閱禮賓的品牌表達和品牌設定檔，以瞭解正確性並與預期體驗一致。
- [ ] **指示和護欄已核准。** 檢閱禮賓指示，並依照適用的品牌指南進行護欄。
- [ ] **技能與整合已正確對應。** 確認所有必要的技能皆已啟用，且正確對應至其整合。
- [ ] **視覺樣式和聊天元件已核准。** 根據品牌期望檢閱視覺樣式和聊天元件。

## 測試和評估

- [ ] **評估集已建立並執行。** 針對每個評估型別建立並執行至少一個評估集：
  - 功能
  - 超出範圍
  - 保護
- [ ] **已檢閱標籤的結果。** 啟動前，請先調查並處理標幟的評估結果。
- [ ] **即時預覽測試已完成。** 使用代表性訪客問題測試即時預覽中的禮賓人員。

## 部署整備

- [ ] **資料串流識別碼已設定。** 確認已為部署設定正確的資料流ID。
- [ 已檢閱] **表面設定。** 確認服務人員僅會出現在預期的頁面上。
- [ ] **已安裝安裝指令碼。** 將安裝指令碼提供給網站團隊，並確認已成功安裝。
- [ ] **B2B可用性已確認（若適用）。** 對於B2B服務生，請確認銷售代表行事曆和即時聊天可用性已設定且可運作。

## 上市後整備

- [ ] **已確認Analytics存取權。** 確認相關利害關係人可以存取必要的分析。
- [ ] **已建立評論步調。** 建立週期性程式，以檢閱交談記錄並新增評估問題。

## 將此檢查清單作為發行需求發佈之前

>[!IMPORTANT]
>
>此檢查清單衍生自指南中說明的工作流程。 這不是正式的產品定義發行閘道。 根據產品和QA定義的發行條件進行驗證，再發佈為正式上線需求。
